日期：2026-10-17；依据[机制复核](TRADITIONAL_BASELINE_FOCUSED_REVIEW_20261017_ZH.md)和[来源表](BASELINE_RELATED_WORK_EVIDENCE_ZH.md)。本文件给出建议和验收条件，**没有启动preflight、实现、训练或评估**。`GO`指下一阶段值得做，`CONDITIONAL_GO`指必须先通过列明条件，`NO_GO`针对当前CoCap完整baseline用途，并非否定论文贡献。

## 1. 只选一个：TR-11，Rao等，JAS 2026

选它的科学原因是能直接检验“显式多目标组织＋几何控制”相对CoCap共享学习策略的价值；有三机/目标仿真、合理的避障路径代价和可核控制推导。选择依据不是预期它输给CoCap。原信息预算作为 `privileged-global`，可在已知目标任务上表现更好。

**决策：CONDITIONAL_GO，先合同/动力学preflight，正式复现暂不启动。**无官方整套源码；从正式pp.989–991及补充pp.1–2重建。当前证据优于只凭摘要的备选，但原保证不能直接迁移到AW9。

### 1.1 从论文重建的边界

下列是S11原算法结构的紧凑数学索引；记号有统一，式号以原文为准。接口与数值退化处理属于CoCap适配，必须单独登记。

| 层 | 可核依据与重建内容 | 必须另行明确的参数/退化情况 |
|---|---|---|
| 分组 | p.990 “Pursuers dynamic allocation”：以各evader为固定中心，按A*路径长分组；超额组转出远离组中心者，直到人数约束满足 | r=3；active数不足时留待招募/报告不可行；转组禁返窗口；迭代预算；何时重求解；同分tie-break |
| 几何槽位 | p.990：目标为中心的内接f边形顶点t_ek；若在CoCap采用等角槽位适配，可写作t_ek=p_e+R_c[cos(φ+2πk/f),sin(φ+2πk/f)] | 原文只述内接f-gon，统一等角相位/更新协议需核对与预注册；捕获阈值为8 m，参考留余量属于适配参数，不是原论文定理 |
| 组内拍卖 | p.990：设d_min、d_max为该pursuer到各槽位的A*长度极值，J=((d−d_min)/(d_max−d_min))²，R=(d_max−d)/(d_max−d_min)，收益B=max(R−J,0)；价格增量为ϑ＋最佳/次佳利润差 | d_max=d_min、无路径、收益并列、非整数成本与ϵ最优解释；原文ϑ条件不能代替数值容差与终止记录 |
| 安全域 | p.990及补充S2–S4：C_l={W:a_lgᵀW≤b_lg−φ_lg^σ−φ_lg^f}；用高斯不确定度与机器人半径内缩分离半平面 | 协方差模型；σ；多边形障碍近似；全队状态；空安全域、边界及重规划处理 |
| 障碍分离QP | 补充S2：min_z zᵀz，s.t. (ξ_i−W_l)ᵀz≥1；由解构造分离面 | 该QP可复用独立SDQP；不能用它直接代替控制层LP |
| 控制 | p.991式(4)、补充S5式(12)–(14)：u=κd，d为机器人到安全域各顶点的偏差；满足L_fh+L_gh·u+c_bh≥0、L_fV+L_gV·u+c_lV≤0及输入约束的LP | 原文为一阶积分器；κ、约束行、CLF朝向、非正margin变量符号逐式核对。Mosek为论文实际solver；更换LP solver需记录验证 |

物理含义：分组减少跨目标资源失衡；拍卖避免多机挤同一槽位；CLF推动向目标对应安全域边界前进；CBF限制穿越安全边界。**人数/距离成功并不隐含CoCap的角间隙约束**，一律由共同evaluator计算normal-capture事件。正f边形f≥3的稳态角间隙为2π/f、比值1，只是几何一致性检查，不是动态可达性证明。

### 1.2 移植接口与主要风险

| 接口 | 需要的工作 | 主要风险/验收方式 |
|---|---|---|
| 世界状态 | active pursuer/target、位置/速度、障碍几何、world bounds、time | 全局版读取范围明示，不伪装成局部token策略 |
| 路径代价 | 按相同障碍/边界/机器人半径建图；A*更新和缓存 | 网格分辨率影响路径和时间；缓存不能使用未来状态；路径代价预处理时间计入 |
| 分配输出 | pursuer→target→slot，临时coalition与版本号 | 目标消失/队员失活、重复slot、频繁切换；记录分配频率、成员变化、无效任务时间 |
| 动作 | 连续速度/加速度参考→真实AW9动作，按真实drag和10物理子步预测 | 原一阶积分器的CBF证明在量化后不成立；不能直接clip后沿用保证。先评估可行性，无法安全实现时停止正式比较或标明适配限制 |
| 相对速度 | 保持pursuer 3、evader 3.5 m/s | 原论文等运动能力条件变化；不得偷偷减慢evader或增加baseline速度 |
| 目标完成 | 只接共同normal-capture移除事件，再更新活动目标/分组 | 论文未证实完整释放生命周期；该event adapter是项目新增，记录其开销 |
| 搜索/恢复 | 无已知目标时用公开、预注册coverage；捕获后释放并恢复；新目标按共同外生协议 | 这些是扩展；不得包装为原论文功能。全局组可以知道全部目标，但也要参加同一恢复测试 |
| 结果 | 每步状态、控制/solver时间、通信、碰撞、capture、恢复/新波事件 | 所有开始回合留在分母；失败时间删失；MPC/LP不可行要有独立reason |

原生算法复建估计**高**：约1–2周量级（单名熟悉控制与本环境工程师、无训练；为工程规划估计，非实测工时）。带AW9、事件/覆盖及配对评估的完整移植约2–4周或更长。若要求恢复形式化安全保证，难度**很高**，不包含在普通复现工时承诺中。

### 1.3 下一阶段的顺序与停止条件

1. 锁定benchmark/evaluator源SHA、resolved配置和seed manifest，确认合同仍为草案还是作者已冻结；设计不依赖Z的共同到达协议。
2. 创建独立复现分支，先建立公式到模块/参数表，保持论文原生积分器与CoCap适配两种命名。
3. 原生小例验证分组容量、slot唯一性、拍卖终止与QP/LP可行性；用解析正多边形、等距离、无路径和不足人数等有物理意义的例子核对，而非只测试函数复述实现。
4. 在AW9上做可达性和安全控制检查；保留饱和、不可行、碰撞原因，明确哪些保证已失效。若需要给baseline更大的动作权限才能工作，停止“共享动力学”主结果，不私自改变合同。
5. 加入正常捕获事件、合理coverage、释放与重新分组；所有增补模块独立标识，做一次性事件语义核查。
6. 用validation seeds调整有限参数和求解预算，与CoCap同等公开预算；冻结后再决定是否开始正式配对评估。

若上述原生重建或AW9可行性不能闭合，TR-11退出正式对照，转核TR-13，或回到TR-01补全文，不改用自制ring冒充TR-11。

## 2. 第二强备选TR-13与MK-WTA储备

### 2.1 TR-13，CEO-DMPC，RA-L 2024

**CONDITIONAL_GO，高至很高难度**。作者机构PDF S13已完整取得，原始公式链明确：§IV式(7)二元变量y_ij最小化追捕者—目标距离和，约束每人至多一目标、每目标恰n_req人；式(8)用z_il分配正多边形槽位；Alg.1构造leader–follower预测参考；§V式(13)–(23)将位置、速度、控制能量、输入变化和soft collision项组为QP，并施加速度/加速度上下界。原生Python3用Quadprog与OR-Tools `pywraplp`；未找到整套源码/运行配置，需逐式重建，不能把单独QP包当本文代码。

它能直接选择n_req=3，也允许更大组；原生包围条件为winding number＝1，加距离和无碰撞。完整原文使其比MK-WTA更容易制定可审查重建合同。低层碰撞项是软约束，不能写成CBF硬安全保证；QP解的安全性由共同swept检查评估。分组写成MILP不等于可以直接套泛化NP-hard最坏界：式(7)/(8)带有运输/匹配结构，若采用等价网络流解法必须说明与原式一致并验最优值。

原模型double-integrator与CoCap有惯性模型更接近JAS的一阶积分器，但仍不是AW9 unicycle；目标向保护区移动的意图先验、圆周巡逻和full real-time通信均不同。需要world/detection-set fusion、实时grouping、slot/leader映射、预测序列、AW9适配、normal事件、目标移除与coverage/新波接口。必须分别统计组更新MILP、每机QP和预测信息字节。原论文不同初始目标数不能当新目标在线到达，Gazebo不能当实物。

可复用独立线性/二次优化库；论文所用OR-Tools MILP backend未明，不能擅称依赖Gurobi，也不能在没有原配置时宣称一键免商业工具。preflight先验证原生分组/slot最优与QP构造，再做AW9与capture/恢复适配。若只需一条传统路线，仍优先TR-11的完整安全区域框架；若其输入模型适配不可行，TR-13是有原文依据的第二路线。

## 3. Local Distributed：为什么没有直接GO的完整文献复现

### 3.1 首选骨架TR-07，非学习KS-COAL

最贴近的是“区域探索→发现任务→邻接链式联盟更新→完成后再组织”的任务结构。正式RA-L卷期为2024。**完整Accelerated方法含监督学习NAC，非学习骨架才属于传统对照**。保留固定K/手工初始化的论文骨架，不为本轮启动HGAN训练。

建议名称 `KS-COAL-CoCap-Adapted`，预期高至很高难度，`CONDITIONAL_GO`：

- 原生重建：以v3 §III-B Alg.1和utility/稳定性定义实现消息buffer、chain switch、最佳方案共识与计算预算；取得正式补充核对运动与utility。v1只提供早期公式对照。
- 搜索：可将区域sweep作为真实文献起点；CoCap障碍、AW9和友机图需要路径/通信适配，不能声称原算法已支持。
- 通信：去掉侦察队无限范围通信/发现广播会改变信息合同和收敛条件；需要消息版本、TTL、延迟与分区处理。若保留广播，只能标privileged communication，不能进matched-local主表。
- 几何：原动态target capture不等价于三机ring。外接经验证控制器、改utility偏好≥3机并把normal capture接入释放层，均是**组合适配贡献**。没有可直接复用的论文官方ring文件。
- 连续服务：明确target移除、已知任务失效确认、coalition解散、恢复区域任务和下一波到达；不把“新资源到达”表述成“新evader到达”。

优势是可解释的动态联盟与计算预算控制；相对CoCap的代价是更多显式任务/utility/消息规则，原结构有scout/SWAT异构能力，改成同质队伍需要明确映射。对CoCap既有优势的判断只限任务合同，不预判成功率或速度。

### 3.2 第二参考TR-10，GB-VCE

已发表Biomimetics 2026、11(7):513；`CONDITIONAL_GO`只针对局部感知/角色/几何模块，**完整多目标复现NO_GO**。可从§4 Alg.1–3重建失联搜索、增长角色与ring tracking。

最大风险不是训练，而是论文伪代码仍使用全体观测、视觉图、Γ、全局argmax/TopK，以及直接可得目标速度。实现真正邻居消息协议、slot编号、分区下leader一致性与有界陈旧状态，是新增工程。另需多目标容量分配与捕获/释放/再搜索；论文单目标持续环绕没有这些功能。MATLAB 2023a仿真、结果CSV可核；无源码/硬件。移植很高，科学主线匹配度低于KS-COAL动态任务骨架。

若作者只接受“完整已发表算法＋忠实复现”的matched-local对照，本轮应报告**尚无合格者**，而不是把上述组合包装成已有方法。

## 5. TR-05辅助启发式的可验证模块

`GO`进入设计preflight，低至中难度；不是已经有完整代码。模块验收需有行为意义：

| 模块 | 最小可验证行为 |
|---|---|
| coverage/spread | 无目标和障碍场景持续运动覆盖；记录发现/漏检而非仅CE；避免边界聚集或停在质心永不巡视 |
| discovery/message | 只有实际表面半径内发现；消息沿允许邻接传播，带target ID、观测时刻、版本和TTL；缓存到期会失效 |
| capacity coalition | 至少3机才提交围捕；不足时招募/搜索；多目标不会无限争抢；距离/到达时间报价、切换迟滞、tie-break明确 |
| geometry/dynamics | 角度slot唯一，径向/切向误差有记录；AW9控制与真实子步动力学一致；避障不改变normal规则 |
| completion/recovery | 共同capture只触发一次释放；任务ID不复用污染；队员可加入其他coalition；无剩余已知目标则重新搜索 |
| repeated service | 与其他方法同波次/总时限；对新目标无预知；失败/未生成波原因留存 |
| tuning/cost | validation seeds预注册调参；计算与消息计入；不只报告最好参数或最好成功局 |
